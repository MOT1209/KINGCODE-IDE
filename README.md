# ⚡ kingCode — محرر أكواد PWA احترافي

محرر أكواد كامل يعمل داخل المتصفح، بواجهة عربية RTL، ويُثبَّت كتطبيق على **الهاتف والآيباد وسطح المكتب**، ويستمر في العمل **دون إنترنت**. بُني بالكامل بـ **Vanilla ES6+** دون أي أطر عمل.

## 📌 الحالة (الإصدار 1.5.1 — مُتحقَّق منه بالكود والاختبارات؛ التفاصيل في `IMPLEMENTATION_PROGRESS.md`)

| منفَّذ ومختبَر | جزئي | غير منفَّذ (لا يوجد أي كود) |
|---|---|---|
| المحرر، الملفات والمجلدات، IndexedDB، المعاينة المعزولة (بوجود اتصال)، PWA قابل للتثبيت، تخطيطات متجاوبة، صفحة الخصوصية | الإكمال التلقائي (تلميحات CodeMirror فقط)، المعاينة دون إنترنت (بشروط المضيف) | طرفية، Git/GitHub، مساعد ذكاء اصطناعي، وكلاء، منشئ مرئي، سوق إضافات، مزامنة سحابية، حزم Android/Windows |

الخطط المستقبلية **تقييم فقط** في `docs/architecture/MULTI_PLATFORM_STRATEGY.md` — لا تُعدّ ميزات.

## ✨ المزايا

- **محرر CodeMirror** (مستنسخ محليًا في `vendor/` — لا يُحمَّل أي CDN وقت التشغيل):
  تلوين صياغة لـ HTML/CSS/JS/JSON/Markdown/Python/SQL/YAML/XML/SVG، إكمال تلقائي،
  إغلاق الأقواس والوسوم، إبراز السطر النشط، والبحث والاستبدال.
- **معاينة مباشرة** داخل iframe معزول (`sandbox`) — تُدمج ملفات المشروع `<link>` و`<script src>` المحلية تلقائيًا.
- **كونسول حقيقي**: كل `console.log/info/warn/error/` من المعاينة يظهر في شريط الكونسول (بحد أقصى 200 سطر).
- **إدارة ملفات ومجلدات**: شجرة مجلدات متداخلة (مسارات مثل `src/lib/app.js`)، إنشاء/إعادة تسمية/نقل/تكرار/تنزيل/حذف للملفات والمجلدات، مجلدات فارغة، تصفية سريعة بالاسم، استيراد ملفات متعددة، تصدير المشروع JSON (بالمسارات) أو كملف HTML واحد. المعاينة تحلّ `<link>` و`<script src>` النسبية داخل المجلدات (`css/a.css`، `../shared/b.js`، `/root.js`).
- **تبويبات** مع نقطة «غير محفوظ»، وحفظ تلقائي في **IndexedDB** (احتياطي `localStorage`).
- **لوحة أوامر** (Command Palette) بأسلوب VS Code، وضع داكن/فاتح، إشعارات Toast، شريط حالة.
- **تخطيط متجاوب حقيقي** (ليس سطح مكتب مصغَّرًا): سطح المكتب بثلاثة أجزاء متجاورة؛ الآيباد بدرج ملفات مؤقت؛ الجوال بجزء واحد بملء الشاشة (المحرر أو المعاينة+الكونسول) وشريط تنقل سفلي (الملفات | المحرر | المعاينة | الإعدادات) بأهداف لمس ≥ 44px.
- **PWA**: التثبيت كتطبيق، أيقونات ماسكا-ابل، اختصارات قائمة سريعة، Service Worker للأوفلاين (والمعاينة الحية بشروط — انظر الحدود).

## ⌨️ اختصارات لوحة المفاتيح

| الاختصار | الوظيفة |
|---|---|
| `Ctrl+P` | فتح **لوحة الأوامر** (بحث الملفات والأوامر) |
| `Ctrl+S` | حفظ يدوي (مع إشارة الحفظ) |
| `Ctrl+Enter` | تحديث **المعاينة** |
| `Ctrl+D` | إظهار/إخفاء **الكونسول** |
| `Ctrl+O` | استيراد ملفات من الجهاز |
| `Alt+→` / `Alt+←` | التنقل بين **التبويبات** (التالي/السابق) |
| `Esc` | إغلاق أقرب نافذة/لوحة مفتوحة |
| `Shift+Enter` | (داخل المحرر) تبديل الكونسول |

> ملاحظة: `Ctrl+P` **يفتح** لوحة الأوامر بدل طباعة المتصفح (يُمنع افتراضيًا).

## 🖥️ المنصات المدعومة

متصفحات حديثة تدعم IndexedDB وService Worker: Chromium (Chrome/Edge) — يُختبر في CI و محليًا؛ Firefox وWebKit — يُختبران في CI عبر Playwright (ليس Safari الحقيقي). التثبيت كـPWA على Android/iOS/سطح المكتب متاح نظريًا ولم يُجرَّب على أجهزة حقيقية. تطبيقات Android/Windows الأصلية **غير موجودة**.

## 🚀 التشغيل محليًا

```bash
node tools/server.js
# ثم افتح: http://localhost:8123/
```

بديل مكافئ إن كنت تستخدم npm: `npm run dev` (خادم نفسه؛ `package.json` صفر تبعيات — لا يجلب أي حزمة).

الخادم ثابت وصفر-تبعيات، ويقدّم `manifest.json` بـ MIME الصحيح `application/manifest+json`.

## ✅ الجودة (CI)

| الأمر | ما يفعله | يتطلب |
|---|---|---|
| `npm test` | 19 فحصًا ثابتًا + 52 اختبار وحدة (`node:test`) + 53 فحص `store:check` | Node فقط، بلا تبعيات |
| `npm run test:e2e` | 50 اختبارًا في متصفح حقيقي (Chromium وFirefox وWebKit في CI عبر `KC_BROWSER`): سير العمل الكامل، انحدارات سلامة البيانات، IndexedDB والترحيل، المجلدات، المحرر (بحث/استبدال/تعليق/إعدادات/ملف 50 ألف سطر)، إمكانية الوصول، العزل الأمني، وتحديث PWA الحقيقي بين نسختين | `npm i` ثم `npx playwright install chromium firefox webkit` |
| `npm run store:check` | جاهزية المتاجر: manifest وأبعاد الأيقونات واللقطات وصفحة الخصوصية وترويسات الاستضافة وغياب استدعاءات الشبكة/الكوكيز (جزء من `npm test`) | Node فقط |
| `npm run package:validate` | مولّدات حزم Android/Windows وفحص مدخلات المالك الناقصة (لا تبني ولا توقّع) — `packaging/README.md` | Node فقط |
| `npm run lint` | ESLint (يلتقط أخطاء الكتابة بين الملفات عبر globals مصرَّح بها) | `npm i` |

التبعيات كلها **dev-only** (`playwright`, `eslint`, `@eslint/js`, `globals`)؛ التطبيق نفسه بلا أي تبعية وقت التشغيل. CI (GitHub Actions) يشغّل 3 مهام على كل push وPR: `verify` (صياغة + `npm test`)، `lint`، `e2e`.

## 🏪 النشر على المتاجر

التطبيق جاهز كـ PWA قابل للتحزيم (أندرويد عبر TWA، ويندوز عبر MSIX): أيقونات، لقطات، صفحة خصوصية (`privacy.html`)، ترويسات استضافة (`vercel.json`/`_headers`) وفحص آلي `npm run store:check`. **لم يُقدَّم شيء للمتاجر ولم تُبنَ الحزم ولم تُجرَّب على أجهزة حقيقية**؛ ما أُنجز وما يتطلب المالك (حسابات، مفاتيح توقيع، أجهزة) مفصّل في `docs/store/README.md`.

## 📱 التثبيت كتطبيق

- **Chrome/Edge (حاسوب):** أيقونة التثبيت في شريط العنوان، أو زر «⬇️ تثبيت التطبيق» داخل kingCode عند ظهوره.
- **iOS/iPadOS:** مشاركة → *إضافة إلى الشاشة الرئيسية* (مطلوب HTTPS أو localhost).
- بعد التثبيت يعمل kingCode بنافذته الخاصة كتطبيق مستقل، **وحتى دون اتصال**.

## 🛜 كيف يعمل الأوفلاين؟

- Service Worker (نسخة `kingcode-v1.5.1`) يخزّن عند التثبيت 60 أصلًا: التطبيق، الوحدات،
  الأيقونات، وملفات CodeMirror كاملة.
- المستندات: **شبكة أولًا ثم الذاكرة** — تحديثات تصل سريعًا، والأوفلاين يعمل دائمًا.
- التحديث لا يعيد تحميل الصفحة تلقائيًا: يظهر إشعار «تحديث جاهز» وتنفّذ «تطبيق التحديث» من لوحة الأوامر.
- الأصول: **ذاكرة أولًا مع تحديث خلفي**.
- مشاريعك تُخزَّن محليًا في **IndexedDB** (سجل لكل ملف، كتابة تفاضلية، سعة بالجيجابايت) مع احتياطي `localStorage` إن تعذّر IndexedDB، وترحيل تلقائي من الصيغة القديمة — لا شيء يغادر جهازك.

## 🌐 النشر

أي استضافة ثابتة تكفي (يُفضَّل مضيف يضبط الترويسات: Vercel/Netlify/Cloudflare Pages؛ GitHub Pages لا يستطيع). انشر **جذر المستودع** كما هو (`vercel.json`: بلا build، `outputDirectory: .`). **حالة النشر:** لم يُتحقَّق من أي نشر حي؛ المشروع `kingcode-ide.vercel.app` لم يكن قابلًا للوصول ولا يظهر في حساب Vercel المتصل وقت التدقيق. بعد النشر نفّذ فحوص `docs/security/HOSTING_HEADERS.md`.

## ⚠️ حدود معروفة

- **المعاينة دون إنترنت** تعمل (Chromium) عبر ذاكرة HTTP بشرطين: أن يرسل المضيف ترويسة `Cache-Control` لـ`sandbox.html` (مُعدّة في `vercel.json`/`_headers`؛ GitHub Pages لا يفعل)، وأن تكون المعاينة عُرضت مرة واحدة على الأقل وأنت متصل. لم يُتحقَّق على مضيف حي. التفاصيل: `SECURITY_AUDIT.md` F-02.
- في Safari/WebKit يُخفي المتصفح تفاصيل أخطاء JavaScript داخل المعاينة المعزولة فتظهر «Script error.» مع شرح السبب.
- الحدود: 60 ملفًا لكل مشروع و2,000,000 حرف للملف المستورد؛ الاستيراد يعرض ما سيُهمَل. التخزين على IndexedDB ويعود إلى `localStorage` (~5 ميجابايت) إن لم يتوفر.
- المعاينة بلا شبكة عمدًا: الصور/الخطوط/السكربتات الخارجية وطلبات `fetch` محجوبة (مُتحقَّق بالاختبار).
- لا طرفية ولا Git ولا ذكاء اصطناعي (الكونسول يعرض مخرجات المعاينة فقط).
- التخزين غير مشفّر ويُشارَك بين صفحات الأصل نفسه؛ التحرير من نافذتين = آخر كاتب يفوز.
- لم يُختبر على أجهزة حقيقية (Safari/iOS، Android WebView، وضع التطبيق المثبّت)؛ Firefox وWebKit يعملان في CI فقط.
